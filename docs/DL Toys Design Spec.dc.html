D&L Toys — Design Spec

Foundations for buttons, inputs, type, and color — the "soft & hopeful" direction. For design + dev handoff.

1. Overview & Tone

D&L Toys distributes free toys to children via a volunteer network. The site's tone is joyful, warm, and hopeful — never corporate or transactional. Copy is written in Spanish, second person informal ("tu"), plainspoken and encouraging. No emoji; enthusiasm comes from copy and color, not decoration.

  • Voice: warm, grateful, community-driven — volunteers and families are thanked often.
  • Never salesy: this is a gift, not a purchase — avoid retail language ("comprar", "precio"). Use "recibir", "regalo", "ordernar".

2. Color Palette

4. Buttons

Signature style: solid fill, fully-committed shadow-pop — a flat 4px offset "shadow" beneath each button (no blur) that reads as a pressable, playful surface. Radius 16px. No hover-lift animation defined yet — flag for dev to add a 1–2px press-down-on-click if desired.

7. Iconography

Simple 1.5–2px stroke line icons (chevrons, arrows, filter, lock, back-arrow), rendered inline as SVG at 14–18px, colored via currentColor/fill to match surrounding text. No icon font or emoji in use. Decorative step illustrations (gift-code, shop, open-gift on the homepage) are original hand-drawn line art from the current site — keep those as-is; only UI icons follow this spec.
